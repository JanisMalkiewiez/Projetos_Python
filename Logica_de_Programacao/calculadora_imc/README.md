### 🧮 Calculadora de IMC

Programa desenvolvido em Python que calcula o Índice de Massa Corporal
(IMC) a partir do peso e da altura informados pelo usuário.

Após realizar o cálculo, o programa apresenta o valor do IMC e sua
respectiva classificação.

**Conceitos praticados:**
- Entrada de dados com `input()`
- Conversão de tipos com `float()` e `str()`
- Variáveis
- Operadores matemáticos
- Exponenciação
- Arredondamento com `round()`
- Estruturas condicionais `if`, `elif` e `else`
