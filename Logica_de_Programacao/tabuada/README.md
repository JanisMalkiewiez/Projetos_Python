# ✖️➕ Super Tabuada Interativa ➖➗

> Um programa dinâmico e inteligente desenvolvido em Python para gerar tabuadas matemáticas na velocidade da luz! 🚀

Esqueça aquelas tabuadas engessadas que só multiplicam! Este script interativo permite que o usuário escolha **qualquer número** e **qualquer operação matemática** (soma, subtração, multiplicação ou divisão) para gerar a tabuada completa de 1 a 10 instantaneamente.

---

### ✨ O que o programa faz?
- 🔢 Solicita um número base para o cálculo.
- 🎛️ Pede ao usuário para escolher uma das 4 operações matemáticas básicas (`+`, `-`, `*`, `/`).
- ⚡ Gera a tabuada de 1 a 10 com base nas escolhas.
- 🛡️ Possui validação básica para evitar que o loop rode se um operador inválido for digitado.
- 🎯 Formata resultados de divisões para exibir apenas duas casas decimais, mantendo o visual limpo.

---

### 🛠️ Conceitos praticados
Neste projeto, foram aplicados fundamentos essenciais da lógica de programação em Python:

- **Entrada de dados:** Interatividade com `input()`
- **Tipagem:** Conversão de strings para inteiros com `int()`
- **Estruturas de repetição:** Uso do laço `for` junto com a função `range(1, 11)`
- **Estruturas condicionais:** Tomada de decisão com `if`, `elif` e `else`
- **Operadores matemáticos:** Manipulação de adição, subtração, multiplicação e divisão
- **Formatação de Strings:** Uso de *f-strings* (`f"{variavel}"`) para saídas dinâmicas e limpas
