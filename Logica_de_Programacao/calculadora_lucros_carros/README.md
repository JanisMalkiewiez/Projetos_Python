### 🚗 Calculadora de Lucros de Carros

Programa desenvolvido em Python que calcula o lucro, prejuízo ou empate financeiro na compra e venda de veículos a partir dos valores pagos, investidos e de venda informados pelo usuário.

Após realizar o cálculo, o programa apresenta o custo total, o valor obtido e o resultado da negociação.

**Conceitos praticados:**
- Entrada de dados com `input()`
- Conversão de tipos com `float()` e `str()`
- Variáveis
- Operadores matemáticos (adição e subtração)
- Concatenação de strings
- Estruturas condicionais `if`, `elif` e `else`
